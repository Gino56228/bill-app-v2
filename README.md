# bill-app-v2
一个简洁的记账应用，使用 Python 开发，支持 Android 打包。

## 功能
- 记录日常收支
- 查看账单统计
- 支持移动端打包

## 技术栈
- Python
- Kivy（UI 框架）
- Buildozer（Android 打包工具）

## 快速开始
1. 克隆仓库：`git clone https://github.com/Gino56228/bill-app-v2.git`
2. 安装依赖：`pip install -r requirements.txt`
3. 运行应用：`python main.py`
4. 打包 Android：`buildozer android debug`
